# Clean11 v0.3.2 - Startup, Shell & Glass Improvements (Alpha)

This alpha brings a unified sign-in startup path, stronger native taskbar suppression, coordinated desktop animations and a redesigned floating top bar. Proudly vibe-coded with OpenAI Codex.

## Startup and native taskbar

- One per-user Task Scheduler logon task starts the dock, top bar, overview/search and widgets in the interactive desktop session, without elevation or a stored password. Settings and setup use the same registration.
- The sign-in launcher waits for the Windows desktop, confirms dock rendering and overview readiness, reports failures and supports up to three retries. Repeated launches reuse existing modules.
- Legacy separate startup entries are retired after task registration succeeds. Setup supports the enabled/disabled startup choice and removes the task on uninstall. Windows startup approval records for other apps are left alone.
- When **Replace the bottom bar** is enabled, Clean11 suppresses Windows taskbar reveals and edge activation, tracks recreated Explorer taskbars and preserves the original shell policy for restoration on exit.
- The Super-key dispatcher recovers from missed releases and silently removed hooks, and still opens Overview when Windows rejects its menu-mask input.

## Interface and animation

- The top bar uses separate glass islands for the active app, a centered date/time with calendar, and system controls. Redundant search and Overview buttons have been removed from the top bar.
- Bluetooth has its own status/dropdown entry. The sound mixer adds default input/output selection and per-app device routing where Windows supports it.
- Dock and top bar slide away during Overview transitions and return with the desktop. Widgets fade with the same scene, with coordinated startup entrance motion and reduced-motion support.
- Background-app popups are positioned clear of the dock, with improved handling when opening an app's context menu.
- Widget and Settings glass use the rendered panel's screen coordinates to improve wallpaper alignment across window borders and display scaling.

## Install or upgrade

Download **Clean11-0.3.2-x64.msi** for **Windows 11 x64**. Existing preferences, widget data and wallpaper backups are retained. Save and close Clean11 Settings before upgrading.

Choose **Start Clean11 when I sign in** during setup, or enable **Settings > System > Start with Windows** later. To hide the native Windows taskbar, enable **Settings > System > Replace the bottom bar**. This remains an explicit preference; installing the update does not force taskbar replacement on for every user or publish anyone's local settings.

The attached `SHA256SUMS.txt` covers the installer built by GitHub Actions from this release tag. Runtime dependencies, Horizon artwork and third-party notices are included.

## Validation and alpha limitations

- Local builds and installer database, cabinet, costing and prerequisite checks passed. All 40 administratively extracted payload files matched their manifest hashes. Startup was exercised through the registered task in a real interactive desktop session, including readiness, repeated invocation, enable/disable, preservation of a manually disabled task, and missing-module failure reporting.
- Forced taskbar reveals were suppressed with replacement enabled, and an external auto-hide policy reset was corrected. A full reboot, prolonged AFK/sleep cycle and complete clean Windows Sandbox install/upgrade/uninstall lifecycle have not been exercised for this release.
- This is an **unsigned alpha**. Windows may show an unknown-publisher or SmartScreen warning. Hardware, shell and per-app audio routing compatibility can vary; unsupported device operations may need Windows Settings.
- The shipping installer uses .NET Framework. The separate .NET 10 candidate remains experimental. No universal displayed-FPS claim is made.
- Turn Horizon off before uninstalling if you want Clean11 to restore the previous wallpaper; local preferences and backups are retained.
