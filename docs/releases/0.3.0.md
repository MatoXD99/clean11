# Clean11 v0.3.0 - Widgets, Horizon & Unified Settings (Alpha)

A calmer desktop, with local widgets, a wallpaper that follows your day, and one redesigned Settings app. Proudly vibe-coded with OpenAI Codex.

## New

- Desktop clock, calendar, local to-do and notes widgets. Add, show/hide, resize and arrange cards from the gallery in Settings. Content and layouts stay on your PC.
- A unified Clean11 Settings app using the widget gallery's glass design, with Appearance, Wallpaper, Dock, Top Bar, Widgets, Overview, Apps & search, and System pages.
- Clean11 Horizon: one original scene in eight lighting states, switched offline using the local Windows clock. Choose Dynamic, Always light, or Always dark, and preview lighting without changing the desktop.
- New installations enable Dynamic Horizon on first launch after backing up the previous background. Turning it off restores that backup. Existing wallpaper preferences are preserved during upgrades.

## Improvements and fixes

- Centered overview rows on wide displays, with equal side margins and no obsolete trailing close-button space.
- Shared entrance/exit progress for overview previews, captions and the top search bar. Interrupted entrance still reverses immediately.
- Less search layout work during expansion/collapse, smoother dock magnification timing, and bounded material caching across displays.
- Minimized-card glass fades through the compositor; plain captions avoid unnecessary glass polling.
- Deferred, lower-priority application-catalog refresh during animations. Search providers are unchanged.
- Desktop cards no longer use cross-process Explorer ownership, and Settings is separated from the desktop widget host. Foreground restoration avoids overriding an unrelated app switch during overview exit.
- Improved startup and native taskbar visibility handling, and a draggable top margin in Settings.
- Horizon ignores disconnected display entries that Windows cannot query, and prevents wallpaper application if its backup journal cannot be saved.

## Install or upgrade

Download **Clean11-0.3.0-x64.msi** below for **Windows 11 x64**. The per-user MSI upgrades earlier Clean11 MSI installations and preserves personal settings, widget content and wallpaper backups. Close Clean11 Settings and resolve any pending save/discard prompt before upgrading. Separately installed development copies may need to be closed as well.

Open **Clean11** or **Clean11 Settings** from Start after installation. Taskbar takeover remains configurable. Other desktop customization tools are not automatically disabled. The package includes runtime dependencies, Horizon artwork and third-party notices. `SHA256SUMS.txt` covers the attached installer built by GitHub from this tag.

## Alpha status and known limitations

This is an **unsigned alpha**, with visual and compatibility issues still possible. A full clean Windows Sandbox install/upgrade/repair/uninstall cycle has not been completed. Mixed-DPI monitors, Explorer restarts, fullscreen games, sleep/resume and device controls need broader real-device validation.

- Horizon uses fixed local clock periods, not astronomical sunrise/sunset. Clean11 must be running for switching. Images change discretely, without crossfades. Artwork is 1672 x 941, not native 4K.
- Horizon backs up native pictures/slideshows, not third-party live wallpaper engines or Windows Spotlight provider configuration. Turn Horizon off before uninstalling to restore the previous background. Private backups/settings are retained.
- Widgets are local-only; Calendar is a month view without account integration. Notes and tasks are plain text in the local Windows account.
- File search coverage depends on the available provider/index. The optional Everything SDK is not bundled. Bluetooth device connection management and advanced network controls may open Windows Settings.
- Animation, geometry, cache and wallpaper checks passed locally. Timing logs measure application updates, not displayed FPS; detailed GPU tracing was unavailable in the development session. No universal FPS improvement is claimed.
- The shipping app remains on .NET Framework; the separate .NET 10 candidate is not the installer runtime.
