# Clean11 — First Public Alpha

A cleaner desktop experience for Windows 11, proudly vibe-coded with OpenAI Codex.

## Included

- Floating dock with smooth magnification, running-app indicators, and window previews.
- Keyboard-driven search for apps, files, folders, and open windows.
- Animated window overview with minimized-window cards.
- Unified Settings for appearance, glass visibility, blur, dock behavior, and live game previews.
- Downloads and background-app menus.
- Shared visual styling built with WPF UI and custom glass effects.

## Installation

Download and run **Clean11-0.1.0-x64.msi** from the assets below.

The installer includes app dependencies, adds Start-menu shortcuts, and offers optional startup with Windows. Open **Clean11** from Start after installation. Windows Sandbox is not required to use the app.

Requires **Windows 11, x64**. Uninstall through Windows Installed apps; personal preferences are retained.

`SHA256SUMS.txt` contains the checksum of the installer attached to this release. This installer is built on GitHub from the tagged source; its checksum may differ from local builds.

## Preview status

**Alpha software: this is an early development build, not a stable release.** Visual glitches, animation issues, and compatibility problems may remain. Top Bar and Desktop modules are planned and are not included.

The installer is unsigned, so Windows may display an unknown-publisher warning. Local package integrity and runtime checks have passed; full clean-install, upgrade, and uninstall testing in Windows Sandbox is still pending. The GitHub build also checks the installer database and prerequisites before publishing.
