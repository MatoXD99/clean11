# Clean11 v0.2.0 - Top Bar & Device Controls (Alpha)

Clean11 now includes a native top bar alongside the dock, search, window overview, and unified Settings. Proudly vibe-coded with OpenAI Codex.

## New in this release

- Floating top bar with the shared glass material, active-app window actions, overview/search shortcuts, battery status, clock, calendar, and power controls.
- A Top Bar page in Clean11 Settings for display selection, fullscreen hiding, screen-space reservation, status modules, and clock seconds.
- Integrated Wi-Fi panel with radio controls, nearby networks, saved-network connect/disconnect/forget, and one-time open/WPA2-Personal connections.
- Integrated Bluetooth panel with Classic/LE discovery, pairing, connection status, and device removal with confirmation. Connection options open Windows' device controls.
- Integrated audio mixer with master and per-app volume/mute, plus default input/output selection for apps and calls.
- Back navigation, bounded device lists, persistent Refresh controls, and shared glass styling throughout the new panels.

## Install or upgrade

Download **Clean11-0.2.0-x64.msi** from the assets below and run it on **Windows 11 x64**. The per-user installer upgrades earlier Clean11 MSI installations and retains personal preferences. Existing development copies outside the installer directory may need to be closed separately to avoid running duplicate modules.

Open **Clean11** or **Clean11 Settings** from Start after installation. Disable other desktop bars in their own settings if they compete for screen space. Clean11 does not automatically disable third-party bars on other computers.

The installer includes runtime dependencies and third-party notices. Uninstall through Windows Installed apps; preferences are retained. `SHA256SUMS.txt` contains the hash for the installer attached to this release. GitHub builds the asset from the tagged source, so its hash may differ from a local build.

## Alpha status and known limits

**This is an early development build. Visual, animation, compatibility, and device-control issues may remain.** The installer is unsigned, so Windows may show an unknown-publisher warning.

- Wi-Fi discovery follows Windows location permissions and adapter policy. New enterprise, WPA3, hidden networks, and persistent credential setup use Windows Settings. Forget is available for saved profiles returned in the nearby list.
- Bluetooth connection/disconnection remains managed by Windows' device controls. Device-specific PIN/setup flows may require Windows Settings. Distinct devices with the same advertised name may appear separately.
- Audio sessions cover the current default multimedia output. Per-app routing remains in Windows Settings. Default-device changes use an isolated Windows policy interface that may vary between Windows builds.
- Live UI inspection covered navigation, Bluetooth discovery, audio device names/dropdowns, and the unavailable Wi-Fi adapter state. Network changes, pairing/removal, and audio routing changes have not been validated on live hardware for this update.
- Package database, cabinet, costing, and host prerequisite checks are performed before publishing. A full clean Sandbox install/upgrade/repair/uninstall cycle, mixed-DPI monitors, fullscreen games, and sleep/resume need broader validation.
- The custom Desktop module remains planned. File search coverage depends on the available index/provider; the optional Everything SDK is not bundled.
